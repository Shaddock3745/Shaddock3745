# Hi, I'm Shaddock 👋

國立臺灣科技大學 應用科技學士學位學程。主要使用 **C#**（Unity / .NET）與 **Java**，喜歡從零把整個系統做出來：規則引擎、搜尋演算法、碰撞偵測、資料驅動架構。

## 作品

| 作品 | 說明 | 技術 |
| --- | --- | --- |
| [Warriors & Spells](https://github.com/Shaddock3745/ChessCard) | 西洋棋 × 卡牌構築的回合制策略遊戲，束搜尋 AI 規劃整回合行動 · [線上試玩](https://shaddock3745.itch.io/warriors-and-spells) | Unity 6、C#、WebGL |

## 技術

- **語言**：C#、Java、Python
- **遊戲**：Unity（2D / URP / WebGL）、Java Swing、JavaFX
- **後端與行動**：Spring Boot、MySQL、Android
- **演算法**：搜尋（Beam Search、A*、BFS / DFS）、計算幾何（GJK）
